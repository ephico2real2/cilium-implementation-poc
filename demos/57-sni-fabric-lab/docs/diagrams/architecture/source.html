sni fabric lab · as built · 2026-10-22

Envoy is the only path between any two parts of the lab

A Docker Compose lab that tests a shared wildcard SNI listener with real clients: a browser with an admin portal, a REST API with Swagger, a raw TCP service, IBM MQ and Postgres. Every component sits on its own network shared only with Envoy, so no hop can bypass it. Built and checked; the layer-by-layer view, with the telemetry stack, is in ../layers/.
