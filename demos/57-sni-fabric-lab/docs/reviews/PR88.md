# Review record: PR #88, the whole demo

The first review of the lab's base (edge, mesh, services, web, MQ, Postgres, scripts, docs),
which had been built without one, together with R1.1 and R1.2. Two independent reviewers, each
in its own git worktree at commit `6d5a505`, with the same ten claims and a live lab they could
read but not change:

- **Codex** (`gpt-5.6-sol`, reasoning `high`): its shell reached Podman through the machine's
  API socket and nothing else (Codex's network proxy, one Unix socket allowed); its own web
  search was on.
- **OB3** (Opus 5.5, `max`).

Each wrote a full fix and a test per finding; the orchestrator checked each claim against the
code or the live lab, decided, and merged one change. The reviews are the scratchpad
`findings.md` and `fixes.patch` of each seat.

## Found by the screenshots, after both reviews

Walking the stores in the browser for chapter 1 showed the VictoriaLogs plugin's settings page
failing with `"not routed "... is not valid JSON`. Envoy's access log named the requests: the
plugin's `POST /select/tenant_ids`, and Grafana's alerting view's `GET /api/v1/rules` on
VictoriaMetrics (which answers `{"status":"success","data":{"groups":[]}}` without vmalert).
Both are read-only; both are now routed, with three route tests.
